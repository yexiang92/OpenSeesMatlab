# OpenSeesMatlab Example Codes

The submitted attachment contains the example codes corresponding to **Sections 3.1–4.5** of the manuscript.

## Installation

Please follow the download and installation instructions provided in the OpenSeesMatlab documentation:

**OpenSeesMatlab Documentation:**  
https://openseesmatlab.readthedocs.io/en/latest/

Install the OpenSeesMatlab toolbox according to the instructions in the documentation before running the examples.

## Running the Examples

After installation, each example can be reproduced by directly running the corresponding MATLAB `.m` file in its directory.

The example folders correspond to the analyses presented in Sections **3.1–4.5** of the manuscript.

## Output files

The figures and their corresponding CSV data are stored in the `figures` directory of each example.

## Recommended MATLAB Version

**MATLAB R2025b or later** is recommended for better support of Live Scripts and related interactive features.
