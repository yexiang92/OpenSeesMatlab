# OpenSeesMatlab

Root toolbox object. Use its properties to access the OpenSees command,
preprocessing, analysis, post-processing, and visualization modules. See
[OpenSeesMatlab at a glance](../getting_started/overview.md) for the module
relationships and [installation](../getting_started/installation.md) for the
first runtime check.

::: OpenSeesMatlab
    handler: matlab
    options:
      parse_arguments: false
      show_root_toc_entry: true
      heading_level: 2
      separate_signature: true
      show_signature_types: true
      signature_crossrefs: true
